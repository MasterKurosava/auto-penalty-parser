# Функциональность приложения

## Графики и аналитика

### Типы графиков
1. **Круговая диаграмма** - распределение по статусам (оплачено/частично/не оплачено)
2. **Столбчатая диаграмма** - топ-5 наиболее частых статей нарушений
3. **Финансовая статистика** - карточка с ключевыми финансовыми показателями
4. **Линейный график** - динамика нарушений за последние 30 дней

### Интерактивность
- Tooltips с детальной информацией
- Адаптивный дизайн (1/2/3 колонки)
- Автоматический пересчет при изменении фильтров
- Цветовая кодировка по статусам

### Сворачивание блоков
- Блок графиков можно свернуть для экономии места
- Блок таблицы можно свернуть для фокуса на аналитике
- Состояние по умолчанию: оба развернуты

## Сортировка таблицы штрафов

### Доступные поля для сортировки:
- ✅ **Статус** (paid) - сортировка по статусу оплаты
- ✅ **Дата** (commitDate) - сортировка по дате нарушения
- ✅ **Госномер** (grnz) - сортировка по государственному номеру
- ✅ **Статья** (article) - сортировка по коду статьи
- ✅ **Сумма** (amount) - сортировка по сумме штрафа

### Логика работы сортировки:
1. **Первый клик** - сортировка по возрастанию (↑)
2. **Второй клик** - сортировка по убыванию (↓)
3. **Третий клик** - сброс сортировки

Активная сортировка отображается стрелкой, неактивные колонки показывают иконку двойной стрелки.

## Фильтрация штрафов

### Фильтр по госномеру
- Работает в реальном времени
- Поиск по частичному совпадению (без учета регистра)
- Активируется после загрузки данных
- Показывает количество отфильтрованных записей

### Пример использования:
```
Загружено: 50 штрафов
Введен фильтр: "181"
Результат: Показано 5 из 50
```

## Фильтры по дате

### Улучшенный интерфейс:
- Поля с типом `date` с улучшенным стилем
- Класс `cursor-pointer` для лучшего UX
- Клик по всему полю открывает календарь браузера
- Адаптивная сетка: 1 колонка (mobile) → 2 колонки (tablet) → 4 колонки (desktop)

## Карточка ЭЦП

### Горизонтальный дизайн:
```
[Иконка] [Название + Статус + Данные] [Кнопка]
```

### Особенности:
- Полная ширина экрана
- Адаптивный дизайн (вертикальный на мобильных)
- Отображение ИИН и UUID в одной строке при подключении
- Убрана кнопка "Выйти из системы"
- Увеличенная кнопка "Подключить ЭЦП" (`size="lg"`)

## Структура дашборда

### Вертикальная компоновка:
1. **Header** (минимальный) - только переключатель темы
2. **Карточка ЭЦП** - на всю ширину
3. **Форма фильтров** - на всю ширину, 4 поля в строку
4. **Статистика** - 4 карточки (всего, оплачено, частично, не оплачено)
5. **Таблица штрафов** - с сортировкой

## Адаптивность

### Breakpoints:
- **Mobile** (< 768px): 1 колонка
- **Tablet** (768px - 1024px): 2 колонки для фильтров
- **Desktop** (> 1024px): 4 колонки для фильтров

### Карточка ЭЦП:
- **Mobile**: вертикальная компоновка
- **Desktop**: горизонтальная компоновка

## Статусы оплаты

| Код | Статус | Цвет | Фон строки |
|-----|--------|------|------------|
| 1 | Оплачен | Зеленый | Белый |
| 3 | Частично | Оранжевый | Оранжевый (светлый) |
| 2, 0 | Не оплачен | Красный | Красный (светлый) |

## Экспорт данных

### Доступные форматы:
- **JSON** - полная структура данных
- **CSV** - все поля в табличном формате

### Особенности CSV:
- Автоматическое определение всех полей
- Экранирование спецсимволов
- Кодировка UTF-8

## Производительность

### Оптимизации:
- `useMemo` для сортировки (пересчет только при изменении данных или параметров)
- Фильтрация на клиенте (без запросов к серверу)
- Ленивая загрузка компонентов

## Доступность

### UX улучшения:
- Понятные иконки для состояний сортировки
- Визуальная обратная связь при наведении на кнопки
- Disabled состояния для фильтров до загрузки данных
- Toast уведомления для всех операций
- Счетчик отфильтрованных записей
