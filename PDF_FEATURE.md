# Открытие PDF постановлений

## Функциональность

### Кнопка "PDF" в таблице
Каждая строка в таблице штрафов содержит кнопку для открытия PDF документа постановления.

### Расположение
Колонка **"Действия"** - последняя колонка справа в таблице

### Внешний вид
- Иконка: 📄 (FileText)
- Текст: "PDF"
- Стиль: Ghost button (прозрачный)
- Размер: Small

## Техническая реализация

### URL формат
```
https://erap-public.kgp.kz/psap/api/pdf/showpdf/av/{id}
```

где `{id}` - это поле `id` из объекта штрафа (PsapCase)

### Пример URL
```
https://erap-public.kgp.kz/psap/api/pdf/showpdf/av/U2FsdGVkX18WLI3syYswF37V1qM3AP79V2Kk0D0QN2xMl3Jk2DWlxMl3JkbF3JoQPe3WcVrWW2
```

### Код открытия
```typescript
const openPdf = (id: string) => {
  const pdfUrl = `https://erap-public.kgp.kz/psap/api/pdf/showpdf/av/${id}`
  window.open(pdfUrl, '_blank', 'noopener,noreferrer')
}
```

### Параметры window.open
- `_blank` - открывает в новой вкладке
- `noopener` - безопасность: новое окно не имеет доступа к window.opener
- `noreferrer` - не отправляет HTTP Referer header

## Использование

1. Найдите нужный штраф в таблице
2. Нажмите кнопку **"PDF"** в колонке "Действия"
3. PDF откроется в новой вкладке браузера
4. Вы можете сохранить PDF или распечатать его

## Содержимое PDF

PDF документ содержит:
- ✅ Официальное постановление об административном правонарушении
- ✅ Дату и место совершения правонарушения
- ✅ Статью КоАП РК
- ✅ Описание правонарушения
- ✅ Сумму штрафа
- ✅ Реквизиты для оплаты
- ✅ Информацию о нарушителе
- ✅ Печати и подписи должностных лиц

## Безопасность

### Защита от XSS
- Используется `window.open` с безопасными флагами
- `noopener` предотвращает доступ к родительскому окну
- `noreferrer` не передает источник перехода

### HTTPS
- Все запросы идут по защищенному протоколу HTTPS
- SSL сертификат проверяется автоматически

## Troubleshooting

### PDF не открывается
1. Проверьте блокировщик всплывающих окон
2. Убедитесь, что у вас есть подключение к интернету
3. Проверьте, что ЭЦП подключена (нужна авторизация)

### Пустая страница
Возможно, PDF еще не сгенерирован в системе PSAP. Попробуйте позже.

### Ошибка 403 (Forbidden)
Проверьте, что ваша сессия ЭЦП активна. Переподключитесь, если необходимо.

## Интеграция с другими функциями

### Экспорт в Excel
При экспорте в Excel также сохраняется поле `ID`, которое можно использовать для формирования ссылок на PDF вручную.

### Фильтрация
Кнопка PDF доступна для всех штрафов, независимо от фильтров.

### Сортировка
Кнопка PDF остается на месте при сортировке таблицы.
