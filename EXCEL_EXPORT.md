# Экспорт данных в Excel

## Возможности

### Автоматическое форматирование
- ✅ **Авторасширение столбцов** - ширина подстраивается под содержимое
- ✅ **Жирный шрифт заголовков** - заголовки выделены жирным
- ✅ **Фон заголовков** - светло-серый фон (#E0E0E0)
- ✅ **Выравнивание** - заголовки выровнены по центру
- ✅ **Максимальная ширина** - столбцы не шире 50 символов

### Структура экспорта

#### Колонки в Excel файле:
1. **Статус** - текстовое значение (Оплачен/Частично оплачен/Не оплачен)
2. **Дата нарушения** - отформатированная дата (дд.мм.гггг чч:мм)
3. **Фамилия** - фамилия нарушителя
4. **Имя** - имя нарушителя
5. **Отчество** - отчество нарушителя
6. **ИИН** - индивидуальный идентификационный номер
7. **Госномер** - государственный регистрационный номер
8. **СРТС** - номер свидетельства о регистрации транспортного средства
9. **Код статьи** - код статьи КоАП
10. **Описание нарушения** - полное описание нарушения
11. **Сумма штрафа** - сумма к оплате
12. **Льгота 50%** - льготная сумма (если применимо)
13. **Номер дела** - номер административного дела
14. **ID** - уникальный идентификатор
15. **RID** - внутренний идентификатор записи

### Название файла
Формат: `штрафы-YYYY-MM-DD.xlsx`

Пример: `штрафы-2025-10-08.xlsx`

## Технические детали

### Библиотека
**xlsx** (SheetJS) - мощная библиотека для работы с Excel файлами

### Алгоритм авторасширения столбцов
```javascript
const colWidths = Object.keys(exportData[0] || {}).map((key) => {
  const maxLength = Math.max(
    key.length, // длина заголовка
    ...exportData.map((row) => String(row[key] || '').length) // длина данных
  )
  return { wch: Math.min(maxLength + 2, 50) } // +2 для отступов, max 50
})
```

### Стили заголовков
```javascript
ws[address].s = {
  font: { bold: true },
  fill: { fgColor: { rgb: 'E0E0E0' } },
  alignment: { horizontal: 'center', vertical: 'center' }
}
```

## Использование

1. Загрузите штрафы через форму запроса
2. Нажмите кнопку **"Excel"** в заголовке таблицы
3. Файл автоматически скачается в формате `.xlsx`
4. Откройте файл в Excel, LibreOffice Calc или Google Sheets

## Пример использования в коде

```typescript
import * as XLSX from 'xlsx'

const exportToExcel = () => {
  // Подготовка данных
  const exportData = cases.map((c) => ({
    'Статус': c.paid === 1 ? 'Оплачен' : 'Не оплачен',
    'Дата': formatDate(c.commitDate),
    // ... остальные поля
  }))

  // Создание листа
  const ws = XLSX.utils.json_to_sheet(exportData)

  // Авторасширение
  ws['!cols'] = colWidths

  // Создание книги
  const wb = XLSX.utils.book_new()
  XLSX.utils.book_append_sheet(wb, ws, 'Штрафы')

  // Скачивание
  XLSX.writeFile(wb, `штрафы-${date}.xlsx`)
}
```
