# Графики и аналитика

## Обзор

Модуль аналитики предоставляет визуализацию данных о штрафах с помощью интерактивных графиков.

## Возможность сворачивания

### Блок графиков
- Кнопка "Свернуть/Развернуть" в заголовке
- Состояние сохраняется при обновлении данных
- По умолчанию: развернут

### Блок таблицы
- Кнопка "Свернуть/Развернуть" рядом с кнопками экспорта
- Позволяет скрыть таблицу для фокуса на графиках
- По умолчанию: развернут

## Типы графиков

### 1. Круговая диаграмма (Pie Chart)
**Назначение**: Распределение по статусам оплаты

**Данные**:
- 🟢 Оплачено (paid = 1)
- 🟠 Частично оплачено (paid = 3)
- 🔴 Не оплачено (paid = 0 или 2)

**Особенности**:
- Показывает только проценты на самой диаграмме (компактный вид)
- Легенда снизу с названиями статусов
- Цветовая кодировка по статусам
- Tooltip показывает количество штук

**Размер**: 200px высота + 36px легенда

---

### 2. Столбчатая диаграмма (Bar Chart)
**Назначение**: Топ-5 наиболее частых нарушений

**Данные**:
- Код статьи на оси X
- Количество нарушений на оси Y
- Tooltip с ПОЛНЫМ описанием статьи

**Особенности**:
- Автоматическая сортировка по частоте
- Полное название статьи в tooltip (не обрезается)
- Дополнительно показывает общую сумму по статье
- Синий цвет столбцов (#3b82f6)
- Tooltip с тенью и border для читаемости

**Размер**: 200px высота

---

### 3. Финансовая статистика (Stats Card)
**Назначение**: Ключевые финансовые показатели

**Метрики**:
1. **Всего штрафов** - общая сумма всех штрафов (большой шрифт)
2. **Оплачено** - сумма полностью оплаченных штрафов (зеленым)
3. **Частично** - сумма частично оплаченных штрафов (оранжевым) ⭐ НОВОЕ
4. **Не оплачено** - сумма неоплаченных штрафов (красным)
5. **Средний штраф** - среднее арифметическое (под разделителем)

**Форматирование**:
- Разделение тысяч (ru-KZ locale)
- Символ валюты: ₸
- Цветовая кодировка для быстрого восприятия
- Компактный layout с правильным учетом всех статусов

---

### 4. Линейный график (Line Chart)
**Назначение**: Динамика нарушений во времени

**Данные**:
- Последние 30 дней с данными
- Количество штрафов по датам
- Общая сумма за день в tooltip

**Особенности**:
- Синяя линия с точками
- Адаптивные метки на оси X (каждая 10-я дата)
- Сортировка по хронологии
- Плавная кривая (type="monotone")

**Размер**: 250px высота, полная ширина (colspan 3)

**Условие отображения**: Показывается только если есть > 1 дня с данными

## Технические детали

### Библиотека
**Recharts** - React компоненты для графиков

### Зависимости
```json
{
  "recharts": "3.2.1",
  "date-fns": "3.6.0"
}
```

### Оптимизации
- `useMemo` для всех вычислений
- Пересчет только при изменении данных
- Условный рендеринг пустых графиков

### Цветовая схема
```typescript
const COLORS = {
  paid: '#16a34a',    // green-600
  partial: '#ea580c', // orange-600
  unpaid: '#dc2626',  // red-600
}
```

## Примеры использования

### Анализ топ нарушений
1. Смотрим столбчатую диаграмму
2. Наводим на столбец для детального описания
3. Видим самые частые статьи
4. Можем принять решение о профилактике

### Отслеживание динамики
1. Смотрим линейный график
2. Видим тренды (рост/падение)
3. Наводим на точку для деталей
4. Анализируем периоды всплеска нарушений

### Финансовый анализ
1. Смотрим карточку статистики
2. Видим общую задолженность
3. Планируем бюджет
4. Отслеживаем средний чек

## Производительность

### Большие данные (> 1000 записей)
- Графики рендерятся быстро благодаря useMemo
- Line Chart показывает только последние 30 дней
- Bar Chart ограничен топ-10 статьями

### Обновление данных
- Автоматический пересчет при изменении фильтров
- Плавные переходы в графиках
- Без мерцания при ре-рендере
