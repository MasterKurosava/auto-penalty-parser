# Структура данных PSAP API

## Получение штрафов

### Endpoint
```
GET /psap/api/cases/load/?pageNum=1&limit=10&orderBy=desc
```

### Заголовки
```
Authorization: Bearer {token}
Cookie: psap-uuid={uuid}; psap-token={token}
Accept: application/json
```

## Важные поля

| Поле | Описание |
|------|----------|
| `id` | Уникальный идентификатор штрафа (зашифрован) |
| `rid` | ID записи (зашифрован) |
| `caseNumber` | Номер дела |
| `commitDate` | Дата нарушения |
| `paid` | Статус оплаты: `1` - оплачен, `0` - не оплачен |
| `lastAp.totalAmount` | Полная сумма штрафа в тенге |
| `lastAp.halfAmount` | Льготная сумма 50% (null если недоступна) |
| `av1f.lastName` | Фамилия нарушителя |
| `av1f.firstName` | Имя нарушителя |
| `av1f.middleName` | Отчество нарушителя |
| `av1f.iin` | ИИН нарушителя |
| `av1o.grnz` | Государственный номер ТС |
| `av1o.srtsNumber` | Номер СРТС/свидетельства о регистрации |
| `article.code` | Код статьи КоАП |
| `article.nameRu` | Описание нарушения |

## Отображение в интерфейсе

### Карточки статистики
- **Всего штрафов**: общее количество записей
- **Оплачено**: количество штрафов с `paid === 1`
- **Не оплачено**: количество штрафов с `paid === 0`

### Таблица штрафов
Колонки:
1. **Статус** - badge с иконкой (оплачен/не оплачен)
2. **Дата** - дата и время нарушения
3. **ФИО** - полное имя нарушителя
4. **Госномер** - номер ТС и СРТС
5. **Статья** - код статьи
6. **Описание** - текст нарушения
7. **Сумма** - полная сумма штрафа
8. **Льгота 50%** - льготная сумма (если есть)

### Визуальные индикаторы
- Неоплаченные штрафы подсвечиваются красным фоном
- Оплаченные штрафы отмечены зеленым badge
- Неоплаченные штрафы отмечены красным badge
